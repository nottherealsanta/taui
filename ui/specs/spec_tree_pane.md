# spec_tree_pane

## editable_nodes
- intent: selected node title updates from keyboard input.
- acceptance: typing mutates selected node title in UI.

## tab_indent
- intent: Tab indents selected node under previous sibling.
- acceptance: parent changes to previous sibling.

## shift_tab_outdent
- intent: Shift+Tab outdents selected node one level.
- acceptance: parent changes to grandparent chain.
